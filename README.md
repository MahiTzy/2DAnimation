# 2D Animation

A browser-based 2D animation project demonstrating animation concepts through web technologies.

## Overview
This repository contains the source for a 2D animation experiment. The implementation details and controls are defined by the project files.

## Technology
The project is maintained as a web project. Check the source files for the exact HTML, CSS, and JavaScript features used.

## Getting Started
```bash
git clone https://github.com/MahiTzy/2DAnimation.git
cd 2DAnimation
```
Open the main HTML entry point in a modern browser. If the project uses browser modules or local assets that require a web server, start a local static server from the project directory.

## Usage
- Open the application in a modern browser.
- Interact with the animation as implemented by the page controls.
- Review the source files to understand the animation loop and rendering logic.

## Development
Edit the relevant HTML, CSS, or JavaScript files and refresh the browser to review changes.
